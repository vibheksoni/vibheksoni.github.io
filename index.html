About

I got into programming trying to understand how the network tools I kept running into on PlayStation actually worked.

That curiosity led me to source code, networking tools, and writing my own code in Notepad before I knew how it worked. I learned Python first, then C, C#, sockets, TCP servers, epoll, and ZMap.

The pattern is the same for everything I build: take something I don’t understand, break it apart, figure out how it works, and build on what I learned.
